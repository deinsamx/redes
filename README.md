# Piezas para redes

Imágenes ya aprobadas de DEINSA · Desarrollo de Infraestructura Sanitaria,
guardadas aquí para poder enlazarlas desde las herramientas con las que se
programan las publicaciones.

Esto no es el sitio web. Aquí solo viven imágenes.

## Cómo se enlaza una pieza

```
https://raw.githubusercontent.com/deinsamx/redes/main/<carpeta>/<archivo>.png
```

Por ejemplo:

```
https://raw.githubusercontent.com/deinsamx/redes/main/s1/P02-L3.png
```

El enlace devuelve la imagen tal cual, con tipo `image/png`. Las herramientas
de programación copian la imagen a su propio servidor en el momento de
agendarla, así que el enlace solo hace falta en ese momento.

## Carpetas

| Carpeta | Qué guarda |
|---|---|
| `s1`, `s2`, `s3`, … | Las láminas de cada semana |
| `pin` | Las versiones verticales, para Pinterest |
| `p01`, `p02`, … | Piezas sueltas de una publicación, como una portada |

Los nombres de archivo son los mismos que ya tienen las piezas en el sitio,
para que una pieza se llame igual en todas partes.

## Qué entra aquí

Solo piezas aprobadas, y solo cuando su publicación ya existe como borrador
o está a punto de crearse. No se suben lotes de semanas futuras que todavía
no tienen borrador.

Una imagen subida aquí queda pública en ese momento, aunque su publicación
esté programada para más adelante.

Si una pieza se corrige, se reemplaza con el mismo nombre: el enlace no
cambia y la versión anterior queda en el historial.
